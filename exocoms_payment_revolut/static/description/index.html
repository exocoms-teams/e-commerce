Revolut Business

Encaissez vos ventes en ligne via la Merchant API de Revolut

Vos clients paient sur une page hébergée par Revolut — carte bancaire, Revolut Pay, Apple Pay, Google Pay, SEPA. Les fonds arrivent sur votre compte Revolut Business, et Odoo suit chaque transaction de bout en bout.

Ce que fait le module

Encaissement

  • Redirection vers la page de paiement hébergée Revolut
  • Carte, Revolut Pay, Apple Pay / Google Pay, SEPA Direct Debit
  • 27 devises prises en charge
  • Bascule Sandbox / Production en un clic

Cycle de vie complet

  • Capture manuelle, totale ou partielle
  • Annulation d'autorisation
  • Remboursements partiels depuis Odoo, avec clé d'idempotence
  • Webhooks signés (HMAC-SHA256) avec protection contre le rejeu

Mise en route

  1. Générez vos clés dans Revolut Business : Merchant → API.
  2. Collez la clé secrète dans le fournisseur de paiement Revolut Business.
  3. Cliquez sur Créer le webhook Revolut : le secret de signature se renseigne tout seul.
  4. Publiez le fournisseur et testez en Sandbox.

Aucune configuration serveur n'est nécessaire. Le module n'utilise que les points d'extension officiels du module payment d'Odoo.

Bon à savoir

  • Un compte marchand Revolut Business actif est requis.
  • L'URL du webhook doit être joignable en HTTPS depuis Internet.
  • Une autorisation non capturée expire au bout de 7 jours côté Revolut.
  • Compatible Odoo 19 uniquement.
