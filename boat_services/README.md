# Boat Services

Module Odoo ajouté pour le projet bateau.

## Fonctionnalités

- Page publique `/boats` pour afficher les bateaux.
- Page détail `/boats/<id>`.
- Formulaire demande de prix `/boats/request-price`.
- Formulaire catalogue `/boats/catalog`.
- Formulaire contact `/boats/contact`.
- Menu back-office `Boat Services > Demandes bateau`.
- Onglet `Boat Services` ajouté sur les produits Odoo.

## Utilisation rapide

1. Installer le module `Boat Services` dans Odoo.
2. Créer ou ouvrir un produit Odoo.
3. Aller dans l'onglet `Boat Services`.
4. Cocher `Produit bateau`.
5. Remplir les informations du bateau.
6. Aller sur `/boats` côté site web.
