# LUMIÈRE Beauty — Odoo.sh Repository

Ce dépôt contient le module personnalisé pour la plateforme e-commerce de **LUMIÈRE Beauty** sur Odoo.

## Modules inclus
* **lumiere_beauty** : Gère l'extension des produits de cosmétiques (rouges à lèvres, sérums, mascaras) avec l'intégration des attributs spécifiques (Fini mat/velours, ingrédients clés, types de peau).

## Déploiement
Chaque push sur la branche `main` déclenche automatiquement un build de production sur Odoo.sh.
