Track products while you shop

Logs views and purchases on e-commerce sites. Data stays in your browser.

Download extension Open dashboard

Features

  • Auto-tracking Detects products on common store pages as you browse.
  • Trend scores Ranks items by views, purchases, and sales signals.
  • Local storage No accounts, no cloud sync, no data sent to servers.
  • Web dashboard Charts and CSV export at /dashboard/.

Install

  1. Download tracker-extension.zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the folder with manifest.json.
  4. Pin the extension to your toolbar.

Same steps work in Edge at edge://extensions.
